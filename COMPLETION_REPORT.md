## 🚀 Quick Deployment (Choose One)

### Option 1: Vercel (EASIEST - 2 Minutes)

1. Go to https://vercel.com
2. Click "New Project"
3. Select "Import Git Repository"
4. Paste: `https://github.com/iBlackFoxprod/moon-reading`
5. Click "Import"
6. **DONE!** Site is live in ~60 seconds

### Option 2: Netlify

1. Go to https://netlify.com
2. Click "New site from Git"
3. Select GitHub and choose your repo
4. Build settings:
   - **Build command:** `npm run build`
   - **Publish directory:** `.next`
5. Click "Deploy"

### Option 3: Manual (Your Server)

```bash
# Clone the repo
git clone https://github.com/iBlackFoxprod/moon-reading.git
cd moon-reading

# Install & build
npm install
npm run build

# Start production
npm start
# Site runs on http://localhost:3000
```
